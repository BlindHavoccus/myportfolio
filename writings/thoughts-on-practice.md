# Thoughts on practice

*A placeholder note. Use this format for short thoughts, reflections and anything that isn't a tutorial.*

I used to think practice meant making something new every day. Lately I draw the same object for a month, and I learn more from that than from any single new piece.

## Why repeat

Repetition removes the question of *what* to draw, so you can focus on *how*. Each study is a little better than the last, and you can see the difference side by side.

![Placeholder cover image](media/writing-02.svg)

> Drawing the same thing twice is not boring. It is the only way to see what changed.

## What I'm working on now

- Slower, more deliberate line work
- Fewer, bolder values
- Finishing things, even when they are imperfect
